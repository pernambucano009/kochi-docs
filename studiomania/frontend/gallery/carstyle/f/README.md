# شرائح ستايلات الكاروسيل لكل مجال

كل مجال بيشوف شرائح الستايل بكلام وصور من مجاله هو:
`f/<المجال>/<الستايل>-0.jpg` و`-1.jpg` و`-2.jpg` (نفس أسماء الملفات اللي في `carstyle/`).

لو المجال مالوش نسخة، بتظهر الشرائح اللي في `carstyle/` نفسها (معمولة دلوقتي لمجال اللياقة، بألوان متنوعة).
الألوان في المعاينة دايمًا متنوعة (مش ألوان براند عميل)، والعميل بيختار وقت الرسم: ألوان الستايل أو ألوان علامته.
