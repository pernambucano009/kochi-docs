# StudioMania

برنامج لصناعة فيديوهات المدربين القصيرة ونشرها، من الفيديو الخام لحد النشر المجدول على السوشيال ميديا.

## الخطوات

1. **تقطيع الفيديوهات:** مكتبة للفيديوهات الخام، وتقطيعها في الأماكن اللي نحددها، بحيث مفيش قطعة أطول من 15 ثانية.
2. **توليد الفيديو بـ Seedance:** عن طريق API بتاع Atlas Cloud، باستخدام القطع وصورة المدرب.
3. **مكتبة التعليق الصوتي:** ملفات الصوت اللي هتدخل في تركيب الفيديو.
4. **ملفات المدربين:** لكل مدرب صورته (لتوليد الفيديو) والأوترو بتاعه (لآخر الفيديو النهائي).
5. **مكتبة الموسيقى:** وجنب كل ملف طوله.
6. **المونتاج النهائي:** ربط الفيديوهات المولَّدة والتعليق الصوتي والموسيقى وأوترو المدرب، مع تعديلات بسيطة (قص، زووم، مكان، صوت). الترشيح: Shotstack.
7. **النشر المجدول:** فولدر للفيديوهات الجاهزة (من البرنامج أو مرفوعة من برا)، والنشر على الحسابات المربوطة في المواعيد المحددة. عن طريق خدمة وسيطة (Ayrshare أو Late أو Postiz).

## قرارات مفتوحة

- طريقة تحديد أماكن القطع في الخطوة 1.
- شكل الطلب لـ Seedance: prompt، وعدد النسخ لكل قطعة.
- الصوت بيتركّب بعد التوليد، ولا بيتبعت لـ Seedance؟
- المنصات اللي هننشر عليها.
