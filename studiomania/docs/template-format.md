# صيغة قالب سمسم كيت (v1)

القالب = فولدر فيه ملف واحد `reel.html` بيرسم الفيديو بالكود من الوقت، ومعاه فيديو عرض وصورة غلاف.
المحرر بيقرا الصيغة دي ويبني لوحده لوحة التحكم: الخانات متقسمة على المشاهد، تحت كل خانة نصيحة، عداد حروف، اختيار خطوط وألوان وصور، وتايم لاين بالمشاهد.
الهدف إن أي حد (فريق سمسم كيت أو فريلانسر) يعمل قالب يشتغل في المحرر والتصدير ومسار القالب من غير ما يلمس كود البرنامج.

## الفولدر

```
library/motion/r/<id>/reel.html     ← القالب نفسه (لازم)
frontend/gallery/<id>.mp4           ← فيديو العرض في المعرض (720×1280)
frontend/gallery/<id>.jpg           ← الغلاف
```

## شكل reel.html

```html
<!doctype html><html><head><meta charset="utf-8"><script src="../../lib/core.js"></script></head><body>
<script>
// سطر أو اتنين بيوصفوا القالب (البرنامج بيقراهم ويدّيهم للمخ لما يكتب أفكار على القالب)
const G1 = "١ · البداية", G2 = "٢ · المنتج", GS = "الشكل العام";
const PR = M.params({
  title: { label: "العنوان", kind: "text", def: "…", group: G1, max: 24, role: "tagline",
           hint: "إحساس مش بيع: ٣–٥ كلمات" },
  img1:  { label: "صورة المنتج", kind: "image", role: "product_img1", def: "", group: G2,
           img: { ratio: "1:1", cut: true, tip: "PNG من غير خلفية والمنتج مالي الصورة" } },
  accent:{ label: "لون البراند", kind: "color", role: "accent", def: "#ff4a0a", group: GS, hint: "…" },
  fHead: { label: "خط العناوين", kind: "font", def: "alexandria", group: GS },
});
M.meta({
  story: "القالب بيحكي إيه في جملتين",
  scenes: [{ name: G1, t0: 0, t1: 3, about: "اللي بيحصل في المشهد" }, { name: G2, t0: 3, t1: 8 }],
  tips: ["أهم نصيحة علشان أحسن نتيجة", "…"],
});
M.reel({ W: 1080, H: 1920, DUR: 8, bg: "#000",
  async init(M) { const hw = await M.font("HD", PR.fHead); /* … */ return { /* … */ }; },
  seek(t, C, M) { /* بيرسم الفريم من t بس (من غير أي حالة محفوظة) */ },
  sound(A) { /* الصوت بالكود: A.kick / A.whoosh / A.pluck / A.groove … */ },
});
</script></body></html>
```

## الخانات (M.params)

كل خانة: `label` (اسمها للعميل) و `kind` و `def` (القيمة الافتراضية: الفيديو لازم يبان حلو بيها). والباقي اختياري:

| المفتاح | معناه |
|---|---|
| `group` | المشهد اللي الخانة فيه (نفس اسم المشهد في `M.meta`). المحرر بيقسّم عليه، ولما العميل يفتحه بيشغّل المشهد ده لوحده |
| `hint` | **نصيحة**: العميل يحط إيه بالظبط علشان يطلع أحسن ناتج (بتدخل كمان للمخ لما يملا الخانة لوحده) |
| `max` | أقصى عدد حروف مقترح. المحرر بيعدّ ويحذّر، والمخ ما بيعدّيهوش |
| `role` | الخانة بتتملا من عقل البراند لوحدها (جدول تحت) |
| `img` | للصور: `ratio` (المقاس) و `cut` (من غير خلفية) و `tip` |
| `script` | للخطوط: `ar` أو `lat` أو `any` |
| `options` | للاختيار: `[["القيمة","الاسم"], …]` |
| `min` / `max` / `step` / `unit` | للأرقام |

**الأنواع (`kind`):** `text` نص · `lines` قايمة (سطر لكل عنصر) · `image` صورة · `color` لون · `font` خط · `select` اختيار · `number` رقم بسلايدر · `toggle` تشغيل/إيقاف

**الأدوار (`role`) اللي بتتملا من عقل البراند:** `brand` الاسم · `product` اسم المنتج · `tagline` جملة البراند · `about` · `cta` الدعوة · `handle` الحساب · `logo` اللوجو · `product_img1..3` صور المنتجات · `accent` و `accent2` ألوان البراند

## الخطوط (M.FONTS)

القالب بياخد الخط بـ `await M.font("HD", PR.fHead)` وبيكتب بيه `${weight} 80px HD`. الخط اللاتيني بياخد الحروف العربي من خط الإسكندرية لوحده.
الخطوط المتاحة متعرّفة في `lib/core.js` (عربي: الإسكندرية، بلكس، شنقا، لاله‌زار، تجوّل، أميري، رقعة · لاتيني: Outfit، Inter، Gabarito، Archivo Black، Anton، Bebas، Instrument Serif، Caveat، Jost).

## قواعد علشان القالب يتقبل

1. الفريم بيترسم من `t` بس: أي فريم ممكن يتطلب في أي وقت (التصدير بيرسم فريم فريم).
2. كل الكلام يتحط بـ `M.fit` علشان يصغر لو طويل، والعربي من اليمين للشمال.
3. أي صورة فاضية ليها شكل بديل (القالب يبان حلو من غير صور).
4. القيم الافتراضية متعمولة لبراند وهمي (مفيش لوجوهات أو أسماء أو صور ناس حقيقيين).
5. كل خانة نصية ليها `hint` و `max`، وكل صورة ليها `img.tip`، وكل المشاهد في `M.meta`.
6. الصوت بالكود من `sound(A)` (من غير ملفات مزيكا عليها حقوق).
7. جوه `M.params` القيم مكتوبة على طول (نص، رقم، مصفوفة، أوبجكت). الثوابت المسموح بيها بس ثوابت نصية فوق (زي أسماء المشاهد `const G1 = "…"`). السيرفر بيقرا الخانات من غير ما يشغّل الكود، فأي متغير تاني بيبوّظ قرايتها.
8. كل كلام بيظهر في الفيديو يبقى خانة (حتى «متصل الآن» و«من ٥») علشان القالب يشتغل بأي لغة.
